# 后台整体重构说明（第三阶段）

本次不是调整间距或配色，而是把后台从「18 个页面各写一份」重建成
「一套导航注册表 + 一套页面组件 + 一致的交互约定」。

## 1. 重构的动因（审计结论）

改造前的问题都能追溯到同一个根因：**没有单一数据源**。

| 症状 | 根因 |
| --- | --- |
| 侧栏有页面但搜索找不到 | 侧栏、面包屑、页面标题各写一份菜单数据 |
| 同一状态在两张页面颜色不同 | 每个页面自己写状态标签的 class |
| 空状态/加载/错误各不相同 | 每个列表页自己写 table 与三种状态 |
| 保存按钮某些页面找不到 | 保存按钮位置由各页面自行决定 |
| 筛选跳转不生效 | 页面读地址栏参数的方式不一致 |

## 2. 新增的基础设施

| 文件 | 作用 |
| --- | --- |
| `navigation.ts` | 后台导航的唯一数据源：分组、图标、权限、关键词、标题、面包屑、搜索 |
| `stores/recent.ts` | 最近访问（只记功能页，不记详情页） |
| `components/AppSidebar.vue` | 可折叠侧栏 + 全局搜索面板（⌘K）+ 最近访问 + 身份区 |
| `components/DataTable.vue` | 统一表格：加载 / 出错 / 空 / 有数据四态 + 分页 + 小屏隐藏列 |
| `components/PageHeader.vue` | 统一页面标题区（标题 + 说明 + 操作按钮） |
| `components/FilterBar.vue` | 统一筛选区（筛选控件 + 计数 + 右侧操作） |
| `components/StatusBadge.vue` | 统一状态标签（订单/工单/卡密/活动一套配色表） |
| `components/AppDrawer.vue` | 统一抽屉（Esc 关闭、锁滚动、三种宽度） |
| `components/SaveBar.vue` | 统一配置操作栏（保存/取消/恢复默认/测试/未保存提示） |

## 3. 应用外壳

- 侧栏可折叠（状态记在本地），折叠后只留图标，标题用 tooltip 补足。
- 顶部栏：页面标题 + 面包屑、通知入口（未读角标）、主题切换、返回前台、
  管理员菜单（系统设置 / 返回前台 / 退出登录）。
- 全局搜索：⌘K 唤起，只列出当前角色有权限打开的页面，回车直达第一条。
- 最近访问：自动记录，最多 6 条，不记详情页。

## 4. 逐页重写结果

| 页面 | 主要变化 |
| --- | --- |
| 总览 | 按「待办 → 工单 → 指标 → 趋势 → 热销/库存 → 最近订单 → 快捷操作」重排；待办只显示非零项；工单中心四个卡片可点且带筛选；趋势图改用真实柱状图 |
| 订单管理 | 服务端分页 + 状态/未发货/买家筛选写进地址栏；批量查单结果用抽屉逐条展示；导出 CSV |
| 客服中心 | 左侧队列（含未读/超时/紧急/退款/卡密/支付快速筛选）+ 右侧处理面板；统计卡与筛选结果一致 |
| 工单面板 | 对话 / AI 工具调用 / 时间线三视图；接管、解决、关闭、交给 AI、转人工、转交客服、自动分配、问题摘要、内部备注、快捷回复 |
| 商品管理 | 服务端分页 + 类型/状态/排序筛选；上下架与推荐只提交变化字段 |
| 卡密库存 | 欠货面板带「提醒补货」；导入/生成抽屉；批量启用/停用/删除；CSV 导出 |
| 活动营销 | 统计卡 + 列表；行内上下架、暂停、复制、删除；数据页入口 |
| 用户管理 | 列表 + 积分调整抽屉（原因写入流水）+ 转账抽屉（未绑定 NodeLoc 时禁用并说明原因） |
| 优惠券 | 抽屉式创建/编辑；适用范围下拉；前台展示开关 |
| 分类管理 | 抽屉式编辑；移除了后台接口不返回的「商品数」列 |
| 通知中心 | 收件箱 + 类型筛选 + 发送/广播抽屉 |
| 操作日志 | 服务端筛选写进地址栏；行内展开详情；CSV 导出 |
| 权限与管理员 | 左侧角色列表 + 右侧权限矩阵，整组全选，未保存状态提示，super_admin 固定只读 |

## 5. 接口改动

只有一处，且是向后兼容的新增字段：

- `POST /api/v1/admin/users/:id/points` 现在接受可选的 `reason`，
  会写进积分流水；不传时沿用「管理员调整」。

## 6. 未改动的部分（按要求）

- NodeLoc OAuth2 登录：未触碰。
- NodeLoc Payment：未触碰，未新增任何支付方式。
- 权限模型、数据库结构：未改。
- 所有既有路由路径保持可用（含 `/knowledge`、`/service/agents` 跳转）。

## 7. 验证

- 管理端与用户端 `vue-tsc` 与 `vite build` 通过；`smoke_test.py` 23 项通过。
- 真实服务验证：
  - 16 条后台路由全部返回 SPA 外壳（200）。
  - 18 个页面依赖的接口全部 200。
  - 写操作实测：积分调整（带原因）、商品补丁更新（名称价格未被清空）、

  - 工单自动分配在无空闲客服时返回 503 与可读原因，属预期行为。
